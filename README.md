## Program Descriptions

### Program 01 – Basic Single Inheritance
Demonstrates single inheritance using a base class and a derived class.

### Program 02 – Protected Member Access
Demonstrates the use of the `protected` access specifier and its accessibility in a derived class.

### Program 03 – Public vs Private Inheritance
Demonstrates different inheritance modes and their effect on member accessibility.

### Program 04 – Multilevel Inheritance
Demonstrates inheritance through a three-level class hierarchy.

### Program 05 – Hierarchical Inheritance
Demonstrates one base class having multiple derived classes.

### Program 06 – Multiple Inheritance
Demonstrates a derived class inheriting from two base classes.

### Program 07 – Multiple-Inheritance Ambiguity
Demonstrates ambiguity in multiple inheritance and resolves it using the scope-resolution operator.

### Program 08 – Constructor and Destructor Order
Demonstrates object construction and destruction order in inheritance.

**Construction:** Base → Derived

**Destruction:** Derived → Base

### Program 09 – Parameterized Base Constructor
Demonstrates calling a parameterized base-class constructor using an initializer list.

### Program 10 – Function Overriding
Demonstrates function overriding using `virtual` and `override`.

### Program 11 – Abstract Class
Demonstrates an abstract class using a pure virtual function.

### Program 12 – Virtual Base Class
Demonstrates virtual inheritance and the diamond inheritance problem.

### Program 13 – Friend Class
Demonstrates how a friend class can access private members of another class.

### Program 14 – Nested Class
Demonstrates a class defined inside another class.

### Program 15 – Vehicle Rental System
A mini-project demonstrating inheritance through a vehicle rental system using different vehicle types.

### Program 16 – Employee Payroll System
A mini-project demonstrating an abstract base class, inheritance, function overriding, and polymorphism for employee payroll.
